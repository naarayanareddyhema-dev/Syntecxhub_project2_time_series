# Time Series & Category Charts

## Project Overview
This project demonstrates data visualization using Python. It includes time series analysis and category-based comparisons using different charts.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Visualizations
- Line chart for sales over time
- Bar chart for category-wise sales comparison
- Pie chart for category contribution

## Output
The project helps in understanding sales trends, category performance, and sales distribution effectively.
